# Snippet: GraphQL Resolver + Schema

**Tags**: graphql, resolver, gqlgen, scaffold
**Used in**: Adding new GraphQL endpoints

## Schema
```graphql
# Location: apidash/internal/graph/schemas/{{name}}.graphql

type Query {
  {{name}}(id: ID!): {{Name}}
  {{name}}s(
    first: Int
    after: Cursor
    where: {{Name}}WhereInput
    orderBy: [{{Name}}Order!]
  ): {{Name}}Connection!
}

type Mutation {
  create{{Name}}(input: Create{{Name}}Input!): {{Name}}!
  update{{Name}}(id: ID!, input: Update{{Name}}Input!): {{Name}}!
  delete{{Name}}(id: ID!): Boolean!
}

input Create{{Name}}Input {
  name: String!
  description: String
}

input Update{{Name}}Input {
  name: String
  description: String
}
```

## Resolver
```go
// Location: apidash/internal/graph/resolver/{{name}}.resolvers.go
// Generated by: task apidash:gql — then implement the methods

func (r *queryResolver) {{Name}}(ctx context.Context, id string) (*ent.{{Name}}, error) {
	return r.Plugin.EntDB.Client.{{Name}}.Get(ctx, id)
}

func (r *mutationResolver) Create{{Name}}(ctx context.Context, input model.Create{{Name}}Input) (*ent.{{Name}}, error) {
	builder := r.Plugin.EntDB.Client.{{Name}}.Create().
		SetName(input.Name)
	if input.Description != nil {
		builder.SetDescription(*input.Description)
	}
	return builder.Save(ctx)
}

func (r *mutationResolver) Update{{Name}}(ctx context.Context, id string, input model.Update{{Name}}Input) (*ent.{{Name}}, error) {
	builder := r.Plugin.EntDB.Client.{{Name}}.UpdateOneID(id)
	if input.Name != nil {
		builder.SetName(*input.Name)
	}
	if input.Description != nil {
		builder.SetDescription(*input.Description)
	}
	return builder.Save(ctx)
}

func (r *mutationResolver) Delete{{Name}}(ctx context.Context, id string) (bool, error) {
	err := r.Plugin.EntDB.Client.{{Name}}.DeleteOneID(id).Exec(ctx)
	return err == nil, err
}
```

## When to Use
Adding any new GraphQL CRUD endpoint.

## Steps
1. Write schema in `schemas/{{name}}.graphql`
2. Run `task apidash:gql`
3. Implement generated resolver stubs
4. Test in GraphQL playground

## Plugin Access
- `r.Plugin.EntDB.Client` → Ent database client
- `r.Plugin.Cache` → Redis cache
- `r.Plugin.RedisClient` → Raw Redis client
- `r.Plugin.RootConfig` → Application config
